The Google sign-in runs on the host PC (the computer running the swarm) — the browser hands the credential back to the machine the CLI runs on, so it can't happen from this page. Either:
• Double-click Connect-AI.bat in your OSHAL install folder, or
• Open a terminal on the host and run gemini once — choose Login with Google and finish in the browser. That writes ~/.gemini/oauth_creds.json, which the bots read.
• Or paste a GEMINI_API_KEY (AI Studio) into .env and restart.
