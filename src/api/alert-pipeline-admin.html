Claim rules —

The set is saved whole. Saving upserts every rule below and deletes every rule the server holds that is not in it, in one transaction — so removing a row here removes the rule. Autonomy is the switch: A0 parks the incident for a human, A1 writes the root cause and the remediation plan and stops, A2 applies that plan.
The rule set is empty, which means unconfigured — not closed. With no rules registered the pipeline has nothing to filter on and accepts everything that arrives. Add at least one rule to make claiming a decision rather than a default.

Topology —

What depends on what, as correlation traverses it. Traverse via is the hub gate: when it is set, a traversal may enter that node only over one of the listed edge types — without it a shared hub collapses the whole estate into one component and correlation looks suspiciously good. Direction certified marks an edge whose direction root-cause ranking is allowed to trust. Saving writes under the operator loader; rows owned by another loader are shown read-only because that loader owns and re-sweeps them. Node props and edge attributes are preserved exactly as loaded.

Replay

Re-runs landing, normalize and claim. Replay is idempotent by construction: the same identity lands on the same incident and bubbles it rather than creating a second one, so replaying twice is not a way to double-count anything.
