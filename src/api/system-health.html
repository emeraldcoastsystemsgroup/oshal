2 Firing now —

Where did my alert go? Each firing alert is drawn with its actual path through the pipeline — landed, normalized, claimed by a rule, consolidated into an incident, turned into a ticket — and the stage it stopped at is marked. An alert that is firing in Prometheus and has no event row never reached this pipeline at all, which looks identical to "quiet" everywhere else.

4 Funnel — —

Every stage, in order, with the lanes that produced it and the change against the stage immediately before it. A stage at zero while the stage feeding it is not is the alarm — that is a pipeline which is up, healthy by every threshold, and doing nothing.
These three are different questions and are routinely swapped for one another. Suppression and dedup make them diverge by an arbitrary factor, so none can be derived from another and none may be read as another.

5 Autonomy ladder —

What each claim rule is allowed to do on its own. A0 parks the incident for a human. A1 writes the root cause and the remediation plan and stops. A2 applies that plan. The bounds beside it are what stops A2 running away: the kill switch, the sliding-hour apply cap, and how much is currently parked instead of acted on.

6 Health signals —

These fire on the ABSENCE of data, not on a threshold. A threshold rule can only fire on data, so a pipeline that has stopped producing data produces no alarms and looks, on every dashboard, like a quiet night.
