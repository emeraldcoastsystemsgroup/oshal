My data

Export or delete everything this deployment holds about you. Both actions are scoped to your signed-in account by the server — the subject is always taken from your session, never from anything this page sends.

Export

One JSON download containing a manifest (which stores were read, how many rows each returned, and which failed) plus a section per store.

The file is built on demand and can be large. Nothing is shown here first, because there is no route that summarises the bundle without generating it — so a preview would be a second full export, not a cheaper one.

Download my data (JSON)

Delete

Deletion is two steps on purpose: this button only asks the server what would be deleted and returns a short-lived token. Nothing is destroyed until you confirm below.

Result

What this surface deliberately does not claim. The API has no read-only endpoint that lists your stores, the known coverage gaps, or your data_lifecycle_audit history — the store list and gap list below arrive only as part of a delete request, and the audit trail is write-only today. So this page shows nothing about your data until you ask for a delete plan, and it cannot show you past exports or deletions at all. Stores marked export-only are retained by design (append-only audit trails, security floors) and are not deleted; the gap list names data the platform holds that this surface does not cover, and a successful delete never implies those were touched.
