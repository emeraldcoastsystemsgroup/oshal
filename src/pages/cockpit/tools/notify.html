Topics are created by whatever produces the notification (a digest job, an alert rail), so there is no catalog to pick from — type the exact topic name the producer uses. It is stored lowercase; a-z 0-9 _ -, up to 64 characters.

Two things this surface cannot show you, stated plainly. (1) There is no route that lists the topics the platform can notify about — only the prefs you have already saved — so an empty list means "you have saved nothing", not "nothing will ever notify you"; unsaved topics fall back to the resolved default channel below. (2) Send test reports exactly what the router returned: delivered, or the real reason it was skipped (quiet hours, channel unavailable, no connected account). It never shows a green tick for a send that did not happen.
