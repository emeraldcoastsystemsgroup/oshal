Two honesty notes about what you are reading. (1) The budget service is deliberately fail-open: when the spend store cannot be read it returns no number rather than zero, and this surface shows — for that. A dash is "unknown", never "$0.00 spent". (2) For the same reason an empty caps table can mean either "no caps are configured" or "the budgets table could not be read" — the API cannot currently tell the two apart, so do not read an empty table as proof that nothing is capped.
