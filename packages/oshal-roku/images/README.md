# Roku channel assets

The PNGs here are **placeholders** (solid OSHAL-brand color generated at the correct dimensions)
so the channel sideloads cleanly. **Replace them with real branded artwork before publishing** —
the Roku Developer Dashboard rejects a submission whose assets are the wrong size.

Required Roku dimensions (referenced by `../manifest`):

| File | Dimensions | Use |
|---|---|---|
| `icon_focus_hd.png` | 290 × 218 | Channel icon, HD devices |
| `icon_focus_fhd.png` | 336 × 210 | Channel icon, FHD devices |
| `splash_hd.png` | 1280 × 720 | Launch splash, HD |
| `splash_fhd.png` | 1920 × 1080 | Launch splash, FHD |

Publishing also requires store artwork uploaded in the dashboard (not in the package):
a **channel poster** (HD 290×218 / FHD 336×210) and a **billboard / store screenshot** set —
see the registration runbook.
