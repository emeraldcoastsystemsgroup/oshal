# OSHAL Visual Identity

## Assets

- [oshal-mark.svg](./oshal-mark.svg)
  - square mark for docs, icons, and slide covers
- [oshal-wordmark.svg](./oshal-wordmark.svg)
  - horizontal wordmark for one-pagers, deck title slides, and README hero areas

## Design Meaning

The mark shows a control-plane core inside a connected swarm. Outer nodes represent runtime agents. The inner ring represents framework governance: tools, routing, workflow, and lifecycle. The center check indicates verified platform operation.

## Usage Guidance

Use the mark when the surface is compact. Use the wordmark when introducing the product or opening a deck.

Do not use the mark to imply full LLM task benchmark completion. Pair it with the precise claim: "dynamic platform insertion is benchmark-ready."
