# Keep a Changelog — quick reference

A reference doc bundled with the skill. On import, `references/` is a RAG candidate
(pass `--rag-collection` to name the collection) rather than inline prompt bloat.

## Guiding principles
- Changelogs are for humans, not machines.
- Every version has its own entry.
- Group the same types of changes together.

## Change groups
- **Added** — new features.
- **Changed** — changes to existing functionality.
- **Deprecated** — soon-to-be-removed features.
- **Removed** — now-removed features.
- **Fixed** — bug fixes.
- **Security** — vulnerabilities addressed.

## Entry shape
```
## [1.2.0] - 2026-07-11
### Added
- A new thing users can now do.
### Fixed
- A bug that used to bite people.
```
